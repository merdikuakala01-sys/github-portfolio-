# Junima Valley SAP Project

## Project Overview
This fictional project focuses on stakeholder analysis for the implementation of a hospital management system at Junima Valley Medical Center.

The objective of the project is to improve patient care, operational efficiency, and communication between departments through the implementation of SAP solutions.

## My Role
Business Analyst

## Key Responsibilities
- Stakeholder identification
- Stakeholder analysis
- Communication planning
- Business needs assessment

## Stakeholders Included
- Hospital Administration
- Physicians
- Nurses
- IT Department
- Patients
- Regulatory Bodies
- Insurance Providers
- Pharmacy & Laboratory Departments
- Vendors / Implementation Partners

## Tools Used
- SAP
- Excel
- Google Sheets
- GitHub

## Key Insights
This project helped me better understand stakeholder management, communication strategies, and the importance of aligning business objectives with system implementation.
